# 1DAM — First-Year Multiplatform Application Development Coursework

This repository contains academic coursework, practical exercises, laboratory assignments, and evaluation projects completed during the first year of the **Multiplatform Application Development** (*Desarrollo de Aplicaciones Multiplataforma* — **1º DAM**) program.

The repository is organized by academic subject, covering relational databases, software development environments and object-oriented programming in Java, algorithmic programming methodology in C, structured and dynamic programming in C++, and client-side web development with HTML, CSS, and JavaScript.

## Subjects

- [`bbdd`](./bbdd/README.md) — **Databases (*Bases de Datos*)**: Relational database design (DDL), data manipulation (DML), single-table and multi-table SQL queries, aggregations, subqueries, views, and stored procedures for MySQL.
- [`entornos`](./entornos/README.md) — **Development Environments (*Entornos de Desarrollo*)**: Java programming fundamentals, control flow, string manipulation, arrays, matrices, object-oriented programming, desktop GUI development with Java Swing / WindowBuilder, and MySQL database connectivity via JDBC.
- [`metodologia`](./metodologia/README.md) — **Programming Methodology (*Metodología de la Programación*)**: Algorithmic problem-solving and structured programming in C, including console games, grid simulations, pointers, structs, file persistence, and classic data structures (stacks, queues, and singly linked lists).
- [`programacion`](./programacion/README.md) — **Programming (*Programación*)**: Procedural and structured programming in C/C++, covering arrays, functions, pass-by-reference, structs, sorting algorithms, dynamic memory allocation (`malloc`/`realloc`/`free`), linked structures, and a full-featured console RPG final project.
- [`web`](./web/README.md) — **Markup Languages and Web Development (*Lenguajes de Marcas*)**: Static web pages, UI layout clones, forms, tables, and interactive client-side web applications built with HTML5, CSS3, and vanilla JavaScript.

## Additional Information

> [!NOTE]
> Within each subject directory, folders are numbered sequentially (`01_`, `02_`, etc.) to reflect the chronological progression of topics throughout the academic year. Folder `00_Examen` or `00_Examenes` in each subject groups exam preparation exercises, midterms (*parciales*), and final practical evaluations.

> [!WARNING]
> Because this repository is an authentic archive of first-year coursework and timed examination submissions, some exercises are partial implementations, contain experimental logic, or depend on local classroom configurations (such as Windows-specific headers or local MySQL instances). Refer to the individual subject README files for specific environment requirements and execution details.
